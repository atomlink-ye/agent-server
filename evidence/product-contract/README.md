# Product-contract evidence

The three JSON files in this directory are byte-for-byte repository mirrors of
the authoritative Human Gate task originals:

- `human-gate-decision.json`
- `human-gate-product-contract-accepted.json`
- `mgr-b-human-gate-format-continuation.json`

The mirrors are checked by whole-file SHA-256 and must retain byte identity.
Do not format, normalize whitespace, reorder keys, or re-serialize these JSON
files. Any change requires governance and a new accepted evidence decision.
